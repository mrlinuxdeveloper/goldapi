# نرخ‌نما — داشبورد GoldAPI

داشبورد فارسی و راست‌چین برای قیمت فلزات گران‌بها با سرور Node.js. کلید GoldAPI فقط روی سرور خوانده می‌شود و به مرورگر ارسال نمی‌شود.

## اجرا

1. Node.js نسخه ۱۸ یا جدیدتر نصب باشد.
2. فایل `.env.example` را به `.env` کپی کنید و مقدار `GOLDAPI_KEY` را در فایل محلی `.env` قرار دهید. کلید را در کدهای `index.html` یا `app.js` نگذارید.
3. در این پوشه اجرا کنید:

   ```sh
   npm start
   ```

4. نشانی `http://localhost:3000` را باز کنید.

`.env` در Git نادیده گرفته می‌شود. اگر کلید در گفت‌وگو یا جای عمومی دیگری افشا شده باشد، آن را از داشبورد GoldAPI باطل و کلید جدید بسازید؛ سپس فقط در `.env` محلی ثبت کنید.

## امکانات

- قیمت لحظه‌ای XAU، XAG، XPT و XPD با ارزهای پشتیبانی‌شده
- نمایش داده‌های عددی پاسخ API، از جمله تغییر، باز و بسته‌شدن قبلی، کف/سقف، bid/ask و اطلاعات واحد/عیار
- نمایش JSON کامل پاسخ API برای فیلدهایی که ممکن است در نسخه یا پلن شما متفاوت باشند
- نمودار کندلی روزانه بر پایه‌ی بازگشایی، سقف، کف و قیمت لحظه‌ای پاسخ API
- محاسبه‌گر ارزش بر اساس وزن؛ برای طلا امکان انتخاب عیار هم وجود دارد
- پراکسی سمت سرور با اعتبارسنجی ورودی و کش کوتاه ۱۵ ثانیه‌ای برای کاهش درخواست‌های تکراری
- به‌روزرسانی خودکار قیمت هر ۱۵ ثانیه؛ در تب مخفی متوقف می‌شود

برای محدودیت‌های طرح اشتراک و دسترسی به فیلدها، تنظیمات حساب GoldAPI را بررسی کنید.
